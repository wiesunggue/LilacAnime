# v10 자막 재검증: 안정화 완료로 판정할 수 없음

검토 기준: `237739289192211929a8b18d48ba2d8f9830bbd9` (v10 배포 소스).

## 실제 번역 큐 실행에서 재현한 결함

알고리즘을 재작성한 시뮬레이션이 아니라 v10 빌드에 남아 있는 `RealtimeSubtitleTranslator.class`를 JVM에서 실행했다. Android 설정/로그와 번역 API 응답만 테스트용으로 대체했다. 네트워크나 모델 지연 없이도 아래 문제가 발생했다. Android 실기기에서 재현했다는 의미는 아니다.

| 사례 | 기대 | 관찰 |
| --- | --- | --- |
| 0~60초의 긴 자막 + 1~2초 대사, 미리 번역 0 | 1.1초에서 짧은 대사 번역 | 긴 자막(0ms)만 완료 |
| 0~60초의 긴 자막 + 매초 대사, 기본 미리 번역 10 | 22초 대사 번역 | 0~10초 대사만 완료, 22초 대사 누락 |
| 1.1초에서 시작 후 0.1초로 1초 되감고 정지 | 아직 번역하지 않은 0초 대사 번역 | 1초 대사만 완료, 0초 대사 누락 |
| 비교: 4.1초에서 0.1초로 되감기 | 0초 대사 번역 | 0초와 4초 대사 완료 |

### F1. 긴 겹침 자막이 번역 창을 가둠 — 높음

`RealtimeSubtitleTranslator.kt:290`은 종료 시각이 현재보다 뒤인 **첫 번째** 대사로 현재 인덱스를 정한다. 긴 간판/설명 자막이 앞에 있으면 이 인덱스가 계속 0으로 유지된다. 300~303행의 번역 창이 그 인덱스에 고정되고 커서는 창 끝에서 대기한다. 기본 미리 번역 10에서도 창을 넘어선 실제 대사는 번역되지 않는다. v10의 원문 대체 때문에 화면이 비지는 않을 수 있지만 한국어 번역이 지속된다는 보장은 없다.

### F2. 1.5초 이하의 되감기는 번역 커서를 복구하지 않음 — 높음

296행의 조건은 1500ms를 초과해 되감았을 때만 커서를 이전으로 돌린다. 아직 번역되지 않은 앞 대사로 1000ms 되감고 일시정지하면, 커서는 뒤에 남아 있고 301행에서 대기하여 번역을 시작하지 않는다. 기본 재생에서 무조건 발생한다는 뜻은 아니며 위 재현은 미리 번역 0 조건이다.

## 기존 검사가 보장하지 않은 것

1. `NativeTranslationTrackTest`는 8초 WAV를 사용하고, 중간부터 일시정지한 상태에서 `getCurrentSubtitleText()` 문자열을 검사한다. 실제 영상 표면에 한국어 픽셀이 계속 표시되는지 검사하지 않는다.
2. [mpv 공식 문서의 sub-text](https://mpv.io/manual/stable/#property-list)는 자막 표시 여부와 무관한 현재 텍스트를 반환한다고 명시한다. 이 문자열 검사를 화면 표시 검증으로 표현하면 안 된다.
3. `SubtitleRenderingTest`의 픽셀 검사는 v10 플레이어가 사용하지 않는 이전 `LibassTranslationOverlay`를 직접 생성한다. 이 검사 통과는 새 네이티브 트랙 표시 경로의 픽셀 검증이 아니다.
4. 버튼 UI 검사는 `TranslationTestPanel`에 가짜 성공/실패 함수를 연결한다. 실제 `AiSettingsScreen`→`TranslationManager`→Keystore→선택한 제공자의 요청/파싱까지 통합 검증한 결과가 아니다.
5. 20초 지연 검사는 재생 시계를 20초간 진행시키면서 한국어 자막이 따라오는지 확인하지 않는다. 번역이 대기하는 동안 원문 시간표가 유지되는지만 확인한다.

기존 JVM 85개 및 Android 12개 통과 사실은 유지되지만, 그 숫자를 실제 사용 안정성의 근거로 확대 해석할 수 없다.

## 수정본을 판정할 때 필요한 기준

- 겹치는 모든 현재 대사 및 가까운 미래 대사를 번역 대상으로 선정한다. 긴 대사 하나가 번역 범위를 가두지 않아야 한다.
- 되감기 크기와 관계없이 아직 번역하지 않은 현재 대사를 다시 선택한다.
- 실제 플레이어 화면과 영상 표면으로 번역 대사의 표시/숨김/배속/싱크를 검사한다. 비디오를 연속 재생하고 지연·실패를 섞어 프레임에서 확인한다.
- 실제 설정 화면을 통해 버튼을 누르고 제공자 설정·키 읽기·HTTP 응답 파싱·오류 표시를 연결해 검사한다. 실제 유료 API/모델 테스트 여부는 따로 명시한다.
- 회차/파일/번역 모드를 연속 전환하는 수명주기 검사를 포함한다.

이번 변경은 **감사 보고서와 재현 자료 보존**이다. 앱 동작을 수정하거나 새 APK를 만들지 않았으며 F1/F2는 배포된 v10에 남아 있다. 사용자가 보고한 휴대폰 증상의 원인이 이 두 결함이라고 단정하지 않는다.
