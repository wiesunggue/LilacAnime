기존 자동 기기 동기화와 진도 변환, 자막 마크업 정리는 유지됩니다.

## 검증

- JVM 회귀 테스트: 배속/탐색, 짧은·긴 Space 입력/반복/취소, 보관함 검색/정렬/필터, 페이지 밖 회차 검색, 다운로드 재시도/취소/최대 횟수.
- GitHub Actions에서 전체 Android 소스 컴파일, 테스트, debug APK 빌드, APK 서명·패키지 정보 검증.
- 실제 기기의 터치·블루투스 키보드·TV 리모컨, 사이트별 실제 스트림, API 키를 사용하는 번역, Cast는 별도 실기기 확인이 필요합니다.

## 아직 PC와 다른 부분

- ffsubsync 전체 음성 분석, 다음 회차 영상/자막 선행 준비, PC용 로컬 AI GPU 실행은 이번 범위에 포함하지 않았습니다.
- Android 플레이어는 항상 가로 전체 화면이므로 PC의 창/전체 화면 전환(F)은 별도 단축키로 제공하지 않습니다.
- PC용 외장 폴더 이동/재탐색과 일반 로컬 영상 열기는 제공하지 않습니다.

## 수동 확인

1. 200화 이상 작품에서 201화를 검색하고, 정렬을 바꾸거나 검색을 지워 페이지가 정상인지 확인.
2. 보관함에서 현재 홈과 다른 소스 작품을 열고 재생/다운로드/이어보기 확인.
3. 외부 키보드로 Space 짧게/길게, 반복 입력, 설정 열기, 앱 전환 후 배속 복귀 확인.
4. 재생 중 회차 목록에서 검색 후 같은 더빙 버전의 다른 회차로 이동. 오프라인에서도 확인.
5. 3배/4배를 저장하고 앱 재시작 후 선택 유지 확인.
6. 작품 다운로드를 묶음으로 멈추고 재개. 재시도 대기 중 일시정지하면 자동 재시작되지 않는지 확인.
7. 4화/4a화 중 하나를 시청 완료 또는 기록 삭제해 다른 회차 기록이 바뀌지 않는지 확인.
