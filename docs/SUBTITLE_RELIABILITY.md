## 자막 옵션의 의미

- **재생할 자막 파일:** 현재 회차에서 사용할 파일 하나.
- **Anissia:** 한국어 자막 목록/파일.
- **Jimaku:** 주로 일본어 원문 자막 목록/파일.
- **Re:Anime / Linkkf:** 해당 영상 사이트에서 제공하는 언어별 자막.
- **사용자 / 저장됨:** 직접 가져왔거나 기기에 저장된 파일.
- **AI 한국어 번역:** 선택한 원문 파일을 번역하여 표시. 다른 자막 파일을 추가 선택할 필요 없음.
- **저장 파일 관리의 포함/제외:** 다음 검색 목록에 보일지를 정하며 즉시 재생 트랙을 선택하는 기능과 구별됨.

## 검증 방식

- 실제 번역 큐 구현에 고정 응답 제공자를 연결하여 40개 연속 대사, 앞뒤 탐색, 제공자 대체, 취소 후 늦은 응답, 재진입, 응답 개수 불일치, 형식/인코딩, 파일 변경을 검사한다.
- Android UI 테스트로 검색 중 취소, 다운로드 중 뒤로가기, 단일 선택 및 번역 옵션을 조작한다.
- Android 네이티브 libass에 번역된 30개 대사를 넣고 각 시각의 비어 있지 않은 렌더링 픽셀, 탐색, 정리를 검사한다.
- mpv에서 실제 로컬 미디어를 재생하여 원문 자막을 숨긴 상태에서 재생 시계만으로 번역이 이어지는지 검사한다.
- 외부 번역 API는 고정 응답으로 대체한다. 실제 유료 API의 성공/쿼터·외부 자막 사이트별 응답·사용자 휴대폰의 재생 완료를 주장하지 않는다.
